# Project Description

An AI-assisted healthcare appointment and
queue management platform that helps patients
find relevant medical specialties, book doctor
appointments, and track their queue progress.

# Proposed Features

- AI-based symptom-to-specialty suggestions
- Doctor directory and search
- Appointment booking
- Digital queue token generation
- Queue position and waiting-time estimation
- Doctor dashboard
- Admin dashboard

# Technology Stack

- Frontend: Next.js, React, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL, Supabase
- AI: Google Gemini API
- Deployment: Vercel, Render
